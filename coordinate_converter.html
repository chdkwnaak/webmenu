사용방법

          
v2.0.0 · 빌드 2026-11-24 · 로컬 오프라인 실행

        


        
      


      

        

          
1. 좌표계 선택

          
상단에서 원본 좌표계와 변환할 좌표계를 먼저 선택합니다. 목록에 없는 좌표계는 사용자 지정 Proj4 직접 입력을 선택한 뒤 Proj4 정의를 입력합니다.

        


        

          
2. 단일 좌표 변환

          
    
            
  1. 단일 1번째 값에는 경도/Easting, 단일 2번째 값에는 위도/Northing을 입력합니다.
    2. 
            
  2. 단일 변환 버튼을 누르거나 입력칸에서 Enter를 누릅니다.
    3. 
            
  3. 단일 변환 결과와 오른쪽 결과 영역에서 변환값을 확인합니다.
    4. 
          

        


        

          
3. 대량 좌표 변환

          
    
            
  1. 좌표를 한 줄에 하나씩 입력합니다. 예: 126.9784147 37.5666805
    2. 
            
  2. txt, csv, xlsx, xls 파일은 드래그하거나 클릭해서 불러올 수 있습니다.
    3. 
            
  3. 파일 모드는 원본 행 연결을 위해 읽기 전용입니다. 좌표 열과 헤더 여부를 확인하고 앞 5건 미리보기 후 변환합니다.
    4. 
            
  4. 직접 입력 버튼으로 파일 연결을 해제하면 기존 편집기를 사용할 수 있습니다.
    5. 
          

        


        

          
4. 축 순서

          
일반 입력 순서는 경도/Easting, 위도/Northing입니다. 원본 자료가 위도/Northing, 경도/Easting 순서라면 입력 좌표 순서 바꾸기를 체크합니다.
          

        


        

          
5. 결과 사용

          
CSV에는 원본 열과 모든 데이터 행을 보존하고 원본행·변환X·변환Y·처리상태·오류내용을 추가합니다. 빈 좌표나 실패 행도 남습니다. 취소한 작업의 부분 결과는 저장할 수 없습니다. 기존 완료 결과는 유지됩니다.

        

        

          
6. 설정과 오프라인 실행

          
좌표계·Proj4·단일/대량 입력 순서·헤더 설정을 이 브라우저에 기억합니다. 저장소가 제한되거나 다른 브라우저로 옮길 때는 설정 내보내기/불러오기를 사용하세요. 저장 폴더 접근은 브라우저 권한을 따릅니다.

          
HTML과 assets 폴더를 함께 보관하세요. 변환과 엑셀 처리는 오프라인에서 동작하며 지도 배경만 온라인 지도 보기 버튼을 눌러 불러옵니다. 데이터는 서버로 전송하지 않습니다. 온라인 지도 요청에는 표시 위치에 해당하는 지도 타일 주소가 사용됩니다.
