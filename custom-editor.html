간단한 사용법

파일을 열고 편집한 다음 저장할 수 있는 간단한 텍스트 편집기입니다.

파일과 기본 편집

  • Open으로 텍스트 파일을 열고 Save로 저장합니다.
  • 파일명 뒤의 * 표시는 아직 저장하지 않은 변경사항이 있다는 뜻입니다.
  • Undo와 Redo로 편집 내용을 되돌리거나 다시 적용합니다.

찾기와 바꾸기

  • Ctrl+F로 찾기, Ctrl+H로 찾아 바꾸기를 엽니다.
  • Next를 누르면 다음 검색 결과로 이동합니다.

열 편집

  • Column 버튼을 켠 뒤 여러 줄을 드래그하여 같은 열을 선택합니다.
  • 문자를 입력하거나 Backspace, Delete를 누르면 선택한 모든 줄에 적용됩니다.
  • 다른 곳을 클릭하면 현재 열 선택만 해제됩니다. Column 버튼을 다시 누르면 열 모드가 종료됩니다.
