현장문서 통합 관리 사용방법

처음 사용할 때는 아래 순서대로 진행하세요. 각 문서의 도구막대에서 페이지 관리와 전용 기능을 사용할 수 있습니다.

  1. 1프로젝트 생성새 프로젝트를 만들고 작업 단위를 구분합니다.
  2. 2공통정보 입력과업명, 조사지역, 날짜와 담당자를 한 번에 설정합니다.
  3. 3문서 추가·작성양식을 선택하고 문서 추가를 눌러 현장 내용을 입력합니다.
  4. 4백업·출력작업 후 전체 백업을 저장하고 필요한 문서를 인쇄합니다.
문서별 주요 기능
  • 안전교육일지: 교육내용과 대상자를 작성하고 현장사진을 추가합니다.
  • 토양 현장기록지: COC 문서를 선택하면 Sample ID, Vial ID, 깊이와 분석항목이 자동 연동됩니다.
  • COC: Sample ID 채우기, 분석항목 선택·편집, 페이지 복제와 결과입력 XLSX 내보내기를 지원합니다.
  • 일일 작업일지: 작업인원, 장비, 작업량과 특이사항을 기록합니다.
페이지와 문서 관리
  • 페이지를 먼저 눌러 선택한 뒤 추가·복제·초기화·삭제 기능을 사용합니다.
  • 입력된 페이지를 삭제할 때는 확인창이 표시되며, 삭제 직후에는 되돌리기로 복구할 수 있습니다.
  • 현재 페이지 초기화는 선택한 페이지만 비우고 다른 페이지와 공통정보는 유지합니다.
COC Container Type 기준
구분대상 항목시료 채취·보관 및 운반 방법

용기 코드: P Plastic · G Glass Bottle · V Vial　 복수 항목: 필요한 용기를 함께 표시(예: TPH + BTEX → G, V)

자동 분류: 다이옥신 → G(세부 시험기준 확인) · 이화학특성 → P

근거
  • ES 07130.c_시료의 채취 및 조제: 2.1.2.2, 2.2.2.3, 2.2.2.5, 2.2.2.4 등
  • “토양오염공정시험기준에 따른 시료채취 및 보관 방법”
모바일과 태블릿 사용
  • 도구막대는 세로로 이동할 때 화면 상단을 따라다니며, 도구 접기로 문서 공간을 넓힐 수 있습니다.
  • 오른쪽 아래의 −, 배율 숫자, +, 맞춤 버튼으로 문서만 확대·축소할 수 있습니다.
  • 정확한 입력과 인쇄 확인은 가로 화면 또는 10인치 이상 태블릿 사용을 권장합니다.
저장·백업·다른 기기에서 사용
  • 작성 내용은 현재 브라우저와 기기에 자동 저장됩니다. GitHub Pages에 올려도 다른 기기와 자동 동기화되지는 않습니다.
  • 다른 기기로 옮길 때는 백업 관리에서 .fieldbackup 압축 파일을 저장하고 대상 기기에서 백업 파일 복원을 사용합니다. 기존 JSON 백업도 읽을 수 있습니다.
  • 5분 간격과 삭제·초기화 직전에 기기 내부 자동 복구본이 생성되지만, 브라우저 데이터 삭제에 대비해 중요한 작업은 파일 백업도 보관하세요.
사진 인식과 XLSX 내보내기
  • 사진 인식은 별도의 OCR 서버가 실행 중일 때만 사용할 수 있으며, 결과를 검토한 뒤 COC에 반영해야 합니다.
  • 결과입력 XLSX는 지정된 엑셀 양식을 선택하면 COC의 Sample ID와 분석 의뢰 여부를 채워 새 파일로 내려받습니다.

권장: 현장 작업을 마칠 때마다 전체 백업을 저장하고, 중요한 페이지는 인쇄 미리보기로 한 번 더 확인하세요.

백업 관리

현재 작업공간

사진을 분리·중복 제거한 압축 백업을 생성합니다. 파일에는 스키마 정보와 SHA-256 무결성 값이 포함됩니다.

백업 파일 복원

.fieldbackup 압축 파일과 기존 JSON 백업을 모두 읽을 수 있습니다. 선택 즉시 복원하지 않고 먼저 내용을 검사합니다.

선택한 백업 파일이 없습니다.

자동 복구본

5분 간격과 삭제·초기화·복원 직전에 이 기기의 IndexedDB에 저장됩니다. 최근 10개와 날짜별 복구본을 보관합니다.

복구본을 확인하고 있습니다.

프로젝트 공통정보

기본 저장은 각 문서의 빈 필드만 채웁니다. 덮어쓰기 저장은 시료·분석 내용은 유지하고 문서의 공통 필드만 새 값으로 교체합니다.

COC 분석항목 편집

프로필의 열을 편집합니다. 삭제한 항목의 기존 체크값은 현재 COC의 모든 페이지에서 함께 제거됩니다. 추가 항목의 용기 종류는 COC에서 직접 입력해 주세요.

Sample ID 형식 예외 검토

형식이 맞지 않지만 COC에 그대로 사용할 Sample ID만 선택해 허용하세요. 허용된 ID는 형식 오류에서 제외되지만 토양 현장기록지 자동 연동에는 포함되지 않습니다. 중복 ID는 허용 여부와 관계없이 계속 오류로 처리됩니다.
