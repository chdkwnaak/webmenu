      메모장 사용 도움말

      처음 오셨나요?
      왼쪽에서 폴더를 만들고, 가운데에서 메모를 선택한 뒤, 오른쪽 편집기에서 내용을 작성하면 됩니다. 편집 내용은 입력을 멈춘 뒤 자동 저장됩니다.

      빠른 시작

      1. 폴더 만들기: 왼쪽 ‘폴더 목록’ 옆의 add_box 버튼을 누르고 이름을 입력하세요.
      2. 메모 만들기: 가운데 위쪽의 ‘새 메모’를 누르세요. ‘모든 메모’에서는 첫 번째 일반 폴더에 저장됩니다.
      3. 내용 작성: 오른쪽 본문을 클릭해 입력하세요. 입력을 멈추면 1초 뒤 자동 저장되며, 아래 상태 표시줄에서 결과를 확인할 수 있습니다.
      4. 메모 찾기: 가운데 검색창에 제목이나 본문 내용을 입력하세요.

      편집 기능

      글자 꾸미기굵게, 밑줄, 기울임꼴과 대제목을 적용합니다.
      할 일 목록체크박스를 넣고 완료한 항목에 취소선을 표시합니다.
      코드 블록소스 코드나 고정폭 텍스트를 보기 좋게 삽입합니다.
      이미지 첨부PNG, JPEG, GIF, WebP 이미지를 압축해 메모 안에 저장합니다. 애니메이션과 투명도는 JPEG 변환 과정에서 사라질 수 있습니다.
      단 나누기본문을 1단, 2단, 3단 순서로 바꿉니다. 모바일 화면에서는 읽기 편하도록 1단으로 표시됩니다.
      글자·단어 수오른쪽 아래에서 현재 메모의 글자 수와 단어 수를 확인합니다.

      정리와 보호

      • 고정: 핀 버튼을 켜면 해당 폴더의 메모 목록 맨 위에 표시됩니다.
      • 잠금: 자물쇠를 켜면 편집과 삭제를 막습니다. 비밀번호 암호화 기능은 아니므로 민감한 정보를 보관하는 용도로는 적합하지 않습니다.
      • 삭제: 일반 메모는 먼저 ‘최근 삭제된 항목’으로 이동합니다. 그곳에서 다시 삭제하거나 ‘비우기’를 누르면 영구 삭제됩니다. 잠긴 메모는 영구 삭제되지 않습니다.
      • 폴더 삭제: 폴더 안의 메모는 휴지통으로 이동합니다. 잠긴 메모가 있으면 폴더를 삭제할 수 없습니다.

      백업과 파일

      • 백업: 왼쪽 아래 백업 버튼으로 모든 폴더와 메모를 JSON 파일로 저장합니다.
      • 복원: 복원 버튼으로 이전 JSON 백업을 불러옵니다. 현재 데이터는 교체되므로 먼저 백업하는 것이 안전합니다.
      • 텍스트 다운로드: 편집기 위 다운로드 버튼은 현재 메모를 TXT 파일로 저장합니다.
      • 저장 위치: 메모는 이 브라우저의 로컬 저장소에만 보관됩니다. 브라우저 데이터를 삭제하거나 다른 브라우저·기기로 이동하면 자동으로 따라가지 않으므로 정기적으로 백업하세요.
